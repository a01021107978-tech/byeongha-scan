# 병하 종목찾기

미국 장 마감 뒤(한국 아침 6시 20분, 화~토) 나스닥·뉴욕·아메리칸 거래소 전 종목에서 병하양봉 규칙으로 후보를 찾아 `out/`에 저장해요.

- **돌파★ / 돌파★★**: 120일선 상승 + 60봉 최고가 첫 종가 돌파 + 거래량 평소 2배(3배 = ★★)
- **되돌림**: 돌파★ 뒤 3~20봉 안에 돌파선까지 내려왔다가 종가가 그 위
- 손절 = 기준선 − 0.2ATR (종가로 깨면 전부) · 반익 = 산 가격 + 손절 폭 (닿으면 절반) · 완익 = 종가가 구름 아래면 나머지
- 거름망: 주가 $10 이상, 20일 평균 거래대금 $2천만 이상, 레버리지·인버스 ETF 제외

결과: `out/scan_latest.txt`(요약), `out/scan_latest.json`(전체), `out/scan_YYYY-MM-DD.txt`(날짜별)

과거 데이터 시험 결과로 고른 후보일 뿐이에요. 매수·매도 권유가 아니에요.
